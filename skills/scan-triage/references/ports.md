# 常见端口的风险与处置要点

端口号只是线索，服务以版本探测（`-sV`）或主机上查到的监听进程为准。服务跑在非标准端口时，按服务本身判断。

## 通用与运维类

| 端口 | 服务 | 常见风险 | 处置要点 |
|---|---|---|---|
| 21/tcp | FTP | 明文传输、匿名登录、弱口令 | 能停则停；需要时改用 SFTP；关闭匿名 |
| 22/tcp | SSH | 口令爆破、旧版本漏洞 | 只允许管理网段访问；禁用口令登录或强口令；核对补丁回移 |
| 23/tcp | Telnet | 明文传输，账号口令可被嗅探 | 关闭，改用 SSH |
| 25/tcp | SMTP | 开放中继、版本漏洞 | 检查中继配置，只允许授权来源 |
| 53/tcp,udp | DNS | 对外开放递归、区域传送泄露 | 关闭对外递归；限制 AXFR |
| 69/udp | TFTP | 无认证读写 | 不用就关；只在隔离网段使用 |
| 111/tcp,udp | rpcbind | 暴露 RPC/NFS 信息 | 限制访问来源 |
| 135/tcp | MS-RPC | 横向移动的常用入口 | 不跨安全区域开放 |
| 137/udp, 139/tcp | NetBIOS | 信息泄露 | 不跨区域开放；不需要就禁用 |
| 161/udp | SNMP | 默认团体名 public/private 泄露配置 | 改团体名或改用 SNMPv3；限制来源 |
| 389/tcp | LDAP | 匿名绑定泄露目录信息 | 禁止匿名绑定；改用 LDAPS |
| 445/tcp | SMB | SMBv1、MS17-010 类漏洞，勒索病毒传播 | 禁用 SMBv1；打补丁；边界和跨区域封堵 |
| 512-514/tcp | rexec/rlogin/rsh | 明文、基于信任关系登录 | 关闭 |
| 873/tcp | rsync | 未授权访问、数据泄露 | 配置认证；限制来源 |
| 1080/tcp | SOCKS 代理 | 开放代理被滥用 | 加认证或关闭 |
| 2049/tcp | NFS | 共享权限过宽 | 收紧 exports，限制来源 |
| 3389/tcp | RDP | 爆破、BlueKeep 类漏洞 | 不对互联网开放；开启 NLA；经 VPN 或堡垒机访问 |
| 4444/tcp | 常被后门、渗透工具默认使用 | 可能是入侵痕迹 | 到主机上查监听进程和来源，按应急流程处理 |
| 5800, 5900/tcp | VNC | 弱口令或无口令 | 设强口令；只走 VPN/堡垒机 |
| 5985, 5986/tcp | WinRM | 远程管理被滥用 | 只允许管理网段 |

## 数据库与中间件

| 端口 | 服务 | 常见风险 | 处置要点 |
|---|---|---|---|
| 1433/tcp | SQL Server | 弱口令、暴露在办公网 | 只允许应用服务器访问 |
| 1521/tcp | Oracle | 弱口令、TNS 相关漏洞 | 同上 |
| 3306/tcp | MySQL | 弱口令、root 远程登录 | 同上；禁止 root 远程登录 |
| 5432/tcp | PostgreSQL | 弱口令、`pg_hba.conf` 过宽 | 同上；收紧 `pg_hba.conf` |
| 6379/tcp | Redis | 未授权访问，可被写文件拿到主机权限 | 绑定内网地址；设置密码；保护模式；限制来源 |
| 9200/tcp | Elasticsearch | 未授权访问、数据泄露 | 开启认证；不对外开放 |
| 11211/tcp,udp | Memcached | 未授权；UDP 可被用于反射放大攻击 | 关闭 UDP；只绑定内网 |
| 27017/tcp | MongoDB | 未授权访问 | 开启认证；绑定内网 |
| 2181/tcp | ZooKeeper | 未授权访问 | 配置 ACL；限制来源 |
| 7001/tcp | WebLogic | 反序列化等历史高危漏洞多 | 核对版本与补丁；控制台不对外 |
| 8009/tcp | Tomcat AJP | Ghostcat（CVE-2020-1938） | 不用就关闭 AJP；升级；设置 secret |
| 8080, 8443/tcp | Web 管理后台/中间件 | 默认口令、管理界面暴露 | 修改默认口令；管理界面只对管理网段开放 |

## 容器与云原生

| 端口 | 服务 | 常见风险 | 处置要点 |
|---|---|---|---|
| 2375/tcp | Docker API（未加密） | 未授权即可控制宿主机 | 关闭；必须开放时改 2376 并启用 TLS 双向认证 |
| 2379/tcp | etcd | 未授权读取集群密钥 | 启用 TLS 与认证 |
| 6443/tcp | Kubernetes API | 匿名访问、权限过宽 | 禁止匿名；最小权限 |
| 10250/tcp | kubelet | 未授权执行命令 | 关闭匿名认证，启用授权 |

## 工控协议（重点）

| 端口 | 协议 |
|---|---|
| 102/tcp | S7comm（西门子 PLC） |
| 502/tcp | Modbus/TCP |
| 2404/tcp | IEC 60870-5-104 |
| 4840/tcp | OPC UA |
| 20000/tcp | DNP3 |
| 44818/tcp | EtherNet/IP |
| 47808/udp | BACnet |

工控协议大多没有认证，能读写就能直接改变生产过程。出现在办公网，或能从办公网访问到，一律按高风险处理：

- 处置：按区域隔离，在边界只放行指定上位机，部署工业防火墙或单向隔离设备。
- 复测：控制扫描速率、避开生产时段、不用破坏性脚本；老旧 PLC 可能因扫描死机，优先在测试环境或维护窗口进行。
