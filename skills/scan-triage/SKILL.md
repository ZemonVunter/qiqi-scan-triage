# 扫描结果研判（scan-triage）

下表是本技能的全部资源，路径相对本技能的基础目录，用到时再读：

| 文件 | 何时用 |
|---|---|
| `scripts/nmap-summary.mjs` | 输入是 Nmap XML（`-oX` 或 `-oA` 生成的 .xml）时运行 |
| `references/false-positives.md` | 判断是否误报、要给核实方法时 |
| `references/ports.md` | 查端口/服务的常见风险与处置要点时 |
| `references/report-template.md` | 输出完整研判、整改清单、告警研判单或教学讲解前 |
| `examples/sample-nmap.xml` | 用户想练习或演示、手头没有数据时 |

## 1. 拿到输入

- 用户给的是文件：先确认路径和格式。原始文件只读不改，新文件写在工作区。
- Nmap XML：运行下面的命令（把基础目录换成实际路径）。脚本只读文件、不联网、不扫描：
  ```
  node "<基础目录>/scripts/nmap-summary.mjs" "<xml 文件>"
  ```
  主机较多时加 `--out <工作区内的报告.md>`，终端只给概览，完整明细写进文件，再按需分段读取。
- Nmap 普通输出（`-oN`）、fscan、漏扫报告导出的 HTML/CSV/文本、告警日志：直接读。文件大时先看表头和前几十行判断结构，再用搜索工具按关键字（如 `open`、`High`、`Critical`、`CVE-`）定位。
- 表格类结果条目很多时，可以在工作区写一次性统计脚本，按漏洞名称、风险等级、主机分组计数；脚本只读原文件。
- 用户粘贴的内容不完整或被截断时，先分析已有部分，再说明缺什么。

## 2. 识别来源与可信度

说明是什么工具、什么扫描方式，以及这对结论意味着什么：Nmap 是否做了版本探测（`-sV`）、是否扫了 UDP、是全端口还是默认 1000 个端口；漏扫是否为登录扫描（authenticated）。结论的可信度和盲区要写出来。

## 3. 按真实风险排序

工具给的等级只作参考，综合四点重新判断：

- 可利用性：是否有公开利用，是否列入 CISA KEV 或有在野利用报道
- 暴露面：互联网可达、办公网、生产网还是隔离区；这个端口本来该不该开
- 资产重要性：边界设备、域控、数据库、生产/工控系统优先
- 现有防护：ACL、防火墙策略、WAF、访问控制能否削弱风险

等级（时限为建议，可按单位制度调整）：

- 紧急：互联网可达且可直接利用，或已有入侵迹象——立即处置
- 高：内网可直接利用的高危漏洞、弱口令、未授权访问、核心资产暴露——一周内
- 中：需特定条件才能利用，或已有补偿措施——一个月内或下个维护窗口
- 低/信息：版本信息泄露、配置不规范——纳入日常加固

## 4. 甄别误报

读 `references/false-positives.md`。重点看：只凭版本号或 Banner 判定的漏洞（发行版常向后移植补丁）、未登录扫描给出的“可能存在”、`tcpwrapped`/`filtered`、按端口号推测的服务名、负载均衡或防护设备代答。每条疑似误报都给出无害的核实方法。

## 5. 告警与日志

逐条归类为：误报 / 扫描探测 / 攻击尝试（未成功）/ 攻击成功，并写出依据（响应码、返回内容、源地址、后续行为）。只命中规则不等于攻击成功。内网地址发起的扫描，先确认是不是单位自己的扫描器或运维主机。

## 6. 入侵迹象优先

出现可疑监听端口或外联、webshell、挖矿进程、内网主机大范围扫描、异常账号时，在回答最前面单独提示：先立即处置（隔离、保全证据、排查横向移动、按单位应急流程上报），再谈加固。

## 7. 输出

先读 `references/report-template.md` 选模板。要点：

- 结论先行。风险清单用表格；同一问题影响多台主机合并为一行，信息级条目汇总说明，不逐条列。
- 处置写到“升级到哪个版本、改哪项配置、加什么访问控制”；补丁暂时打不上（老旧系统、工控设备、业务不能停）时给出补偿措施；会重启或影响业务的操作要标明。
- 复测：给出由用户在授权范围内执行的命令和参数。涉及生产/工控网络和老旧设备时，提醒控制扫描速率、避开生产时段、不用破坏性脚本。
- 用户要“整改清单”或“报告”时，写成工作区里的 Markdown 文件，告诉用户路径；有 present 工具时用它交付文件。

## 8. 教学模式

用户说“讲解”“教学”“练习”，或明显在学习时：

- 每个判断按“看到了什么 → 说明什么 → 所以怎么做”讲清楚，并解释涉及的术语（如 `-sV`、`filtered`、CVSS、补丁回移）。
- 结尾留一两道思考题，不直接给答案，等用户作答后再点评。
- 想练习但没有数据时，用 `examples/sample-nmap.xml`。它是虚构的实训网段 192.168.56.0/24，不对应任何真实主机。

## 9. 边界

不执行扫描、爆破或攻击工具；不提供攻击载荷或可直接利用的代码；联网搜索不带用户的 IP、主机名、域名、单位名称；不确定的写“待核实”。
